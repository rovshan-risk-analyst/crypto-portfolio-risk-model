# Crypto Portfolio Risk Model

This project analyzes cryptocurrency portfolio risk using Python and Jupyter Notebook.

## Assets
- BTC
- ETH
- BNB

## Implemented Metrics
- Daily Returns
- Mean Return
- Volatility
- Correlation Analysis
- Covariance Analysis
- Sharpe Ratio
- Max Drawdown
- Historical VaR
- Parametric VaR
- CVaR
- VaR Breaches
- Backtesting
- Kupiec Test
- Traffic Light System

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy

## Project Features
- Risk vs Return visualization
- Portfolio performance analysis
- Statistical risk measurement
- VaR model validation using backtesting
- Professional risk reporting
